# Demo feedback - owner test round and change list

Status: template. Filled by the owner after testing the live demo (Sprint 1.3 exit).

## How to test
1. Open the demo on desktop first, then on the phone.
2. Walk the tour: sale (FEFO, hold, void) - purchase (bonus, per-batch price) - item card - customers and cash receipt - shortages to purchase - reports - other branch and transfer - deleted view and restore.
3. Use the orange "ملاحظة" button on any screen. The screen name is captured automatically. Press "نسخ الكل" and send the markdown table in the chat.
